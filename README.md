# ffxiv-court-generator

FFXIVキャラクター紹介用の、非公式カードジェネレーターです。  
キャラクター情報や交流スタンスを入力し、SS画像を組み合わせて、SNS投稿向けのカード画像を作成できます。

This is an unofficial character card generator for FFXIV.  
You can enter character information, select your interaction style, upload a screenshot, and export a card image for SNS posts.

## 公開ページ / Live Page

GitHub Pagesで公開しています。  
https://ichigo-git.github.io/ffxiv-card-generator/

## 主な機能 / Features

- キャラクター情報の入力 / Character profile input
- SS画像のアップロード / Screenshot upload
- 画像の位置・サイズ調整 / Image position and size adjustment
- テーマ切り替え / Theme switching
- 日本語 / 英語表示切り替え / Japanese / English display toggle
- PNG / JPG / WEBP形式での画像出力 / Export as PNG, JPG, or WEBP
- 出力サイズの選択 / Export size selection

## データの取り扱い / Data Handling

入力したキャラクター情報やアップロードした画像は、サーバー上には保存されません。  
処理はブラウザ上で完結します。

Character information and uploaded images are not stored on a server.  
All processing is completed locally in your browser.

## 推奨環境 / Recommended Environment

PCブラウザでの利用を推奨しています。  
スマートフォンでも利用できるよう調整していますが、画像の細かい位置調整などはPCの方が操作しやすい場合があります。

A PC browser is recommended.  
Mobile devices are also supported to some extent, but detailed image adjustments may be easier on a PC.
