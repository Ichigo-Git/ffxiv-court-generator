# ffxiv-court-generator

FFXIVのスクリーンショットを、トランプカード風に飾る非公式ジェネレーターです。  
キャラクターを主役に、ランク・スート・ジョブ情報などを組み合わせてカード画像を作成できます。

This is an unofficial playing-card-style generator for FFXIV screenshots.  
You can create character cards by combining your screenshot with a card rank, suit, job information, and other details.

FFXIV 스크린샷을 플레잉 카드 스타일로 꾸밀 수 있는 비공식 제너레이터입니다.  
캐릭터를 중심으로 카드 랭크, 수트, 잡 정보 등을 조합해 카드 이미지를 만들 수 있습니다.

## 主な機能 / Features / 주요 기능

- キャラクター情報の入力 / Character information input / 캐릭터 정보 입력
- SS画像のアップロード / Screenshot upload / 스크린샷 업로드
- 画像の移動・拡大縮小・回転 / Move, resize, and rotate images / 이미지 이동 / 확대·축소 / 회전
- カードランクの選択 / Card rank selection / 카드 랭크 선택
- 任意の数字入力 / Custom number input / 원하는 숫자 입력
- スートの選択 / Suit selection / 수트 선택
- メインジョブの設定 / Main job selection / 메인 잡 설정
- ジョブの選択・表示 / Job selection and display / 잡 선택 및 표시
- 2種類のデザインテーマ / Two design themes / 2가지 디자인 테마
- 背景色4種＋カスタムカラー / Four preset background colors + custom color / 배경색 4종 + 사용자 지정 색상
- 日本語 / 英語 / 韓国語表示切り替え / Japanese / English / Korean display toggle / 일본어 / 영어 / 한국어 표시 전환
- PNG / JPG形式での画像出力 / Export as PNG or JPG / PNG / JPG 형식으로 이미지 출력
- 3種類の出力サイズ / Three export sizes / 3가지 출력 사이즈

## データの取り扱い / Data Handling / 데이터 처리

入力したキャラクター情報やアップロードした画像は、サーバー上には保存されません。  
処理はブラウザ上で完結します。

Character information and uploaded images are not stored on a server.  
All processing is completed locally in your browser.

입력한 캐릭터 정보와 업로드한 이미지는 서버에 저장되지 않습니다.  
모든 처리는 브라우저에서 완료됩니다.

## 推奨環境 / Recommended Environment / 권장 환경

PCブラウザでの利用を推奨しています。  
スマートフォンでも利用できますが、画像の細かい位置調整・拡大縮小・回転などはPCの方が操作しやすい場合があります。

A PC browser is recommended.  
Smartphone use is supported, but detailed image positioning, resizing, and rotation may be easier on a PC.

PC 브라우저 사용을 권장합니다.  
스마트폰에서도 사용할 수 있지만, 이미지의 세밀한 위치 조정, 확대·축소, 회전 등의 작업은 PC에서 더 편리할 수 있습니다.
